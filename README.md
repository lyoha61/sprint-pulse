# SprintPulse — Dev Team Dashboard

## Описание
SprintPulse — прототип дашборда для тимлида разработки, который позволяет отслеживать ключевые метрики команды за спринты и быстро оценивать состояние разработки.

Цель — дать визуальное представление о производительности, качестве и стабильности работы команды без ручного сбора данных из разных систем.

---

## Функциональность

- Просмотр метрик команды за 3–4 спринта
- Переключение между спринтами
- Отображение ключевых KPI:
  - выполненные задачи
  - баги
  - velocity команды
  - время code review
  - процент задач в срок
  - частота релизов
- Подсветка проблемных метрик (status: OK / Warning / Critical)
- Интерактивные графики
- AI-инсайты по выбранному спринту (опционально)

---

## Технологии

### Frontend
- Vue 3 (Composition API)
- Vite
- Tailwind CSS

### Визуализация
- Chart.js / ECharts

### Данные
- Mock data (JSON / JS modules)
- Имитация API слоя (services layer)

---

## Архитектура

- Frontend-only приложение
- Слой сервисов для абстракции данных (подготовка под будущий backend)
- Mock API вместо реального сервера

---

## Критерии реализации

- Рабочий интерактивный прототип
- Реалистичные данные за несколько спринтов
- Понятные и интерпретируемые метрики
- Быстрое восприятие состояния команды на главном экране
- Минимум 1 интерактивный элемент (переключение спринтов / фильтр)
- Визуальная индикация проблемных зон
